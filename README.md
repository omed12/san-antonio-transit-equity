# san-antonio-transit-equity

## Objective: To map the intersection of extreme urban heat and health-vulnerable populations in San Antonio.

## Methods: RStudio, sf, tmap, tidycensus, tigris.

## Key Finding: My descriptive analysis shows Bexar County census tracts have a massive 25.7°F spread in average summer surface temperatures, with the hottest tract peaking at 126.6°F.
